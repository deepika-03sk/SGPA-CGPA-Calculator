# SGPA & CGPA Calculator

A simple Java console-based application to calculate SGPA and CGPA.

## Features

- Student details
- SGPA calculation
- CGPA calculation
- Marks to grade-point conversion
- Credit-based calculation

## Technologies Used

- Java
- Scanner
- Conditional Statements
- Methods

## How to Run

Compile the program:

```bash
javac SGPA_CGPA.java
